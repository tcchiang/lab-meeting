# Lab Meeting Materials

Welcome to our lab meeting materials repository! This repository organizes resources from our lab meetings by topic.

## Topics

Browse materials by topic:

- **[Reinforcement Learning (RL)](RL/)** - Materials related to RL research and discussions
- **[Large Language Models (LLM)](LLM/)** - Materials related to LLM research and discussions
- **[Neural Architecture Search (NAS)](NAS/)** - Materials related to NAS research and discussions

## How to Use

1. Navigate to the topic folder that interests you
2. Each topic folder contains:
   - A dedicated README with detailed information
   - Presentation slides, papers, code examples, and other materials
3. Feel free to upload new materials and update the respective README

## Contributing

To add materials:
1. Upload your files to the appropriate topic directory
2. Update the README.md in that directory to reference your files
3. Include a brief description and links to help others find the content

---

For questions or suggestions, please open an issue or contact the lab organizers.
